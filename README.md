# 🦺 Умный ИИ-помощник по технике безопасности (Text-to-SQL Demo)

Интерактивный веб-прототип на базе **Streamlit** для демонстрации возможностей семантического поиска и подхода **Text-to-SQL** в сфере охраны труда и промышленной безопасности.

Приложение показывает, как можно использовать структурированную графовую онтологию (базу знаний из триплетов) для автоматического формирования нарядов, чек-листов и инструктажей для работников строительства и ЖКХ без галлюцинаций (без LLM в контуре принятия решений).

---

## 🌟 Возможности и сценарии (Use Cases)

В приложении реализовано 5 ключевых бизнес-сценариев:

1. **🧱 Плановый наряд (строительство)**
   Мастер выбирает вид работ (например, "Высотные") и роль ("Монтажник"). Приложение генерирует точный чек-лист: обязательные СИЗ, опасные факторы, предписания и запреты.
2. **🧪 Тест по знанию ТБ**
   Автоматическая генерация тестов на внимательность для проверки знаний работников перед допуском на объект.
3. **🚨 Аварийные работы ЖКХ**
   Экстренная карточка действий при авариях (например, прорыв труб в подвале). Показывает специфические риски (загазованность, затопление) и немедленные действия до спуска бригады.
4. **🏠 Плановые и заявочные работы ЖКХ**
   Формирование чек-листов для рутинных задач (обслуживание систем, уборка) с учетом обязательных инструктажей.
5. **📑 Анализатор нормативных требований (Матрица комплаенса)**
   Макро-сценарий для ПТО. При выборе типа объекта (Жилой дом, Промышленный объект и т.д.) и этапа жизненного цикла (от проектирования до сноса) формируется полная матрица применимого законодательства (883н, 384-ФЗ, 116-ФЗ) и глобальных рисков.

---

## 🧠 Алгоритм и данные (Онтология)

Приложение работает **детерминированно** (без нейросетей-генераторов) на основе заранее сформированной онтологической базы знаний. В будущем этот алгоритмический фильтр легко заменяется на реальный `text-to-SQL` движок поверх реляционной базы данных (Postgres, DuckDB).

Данные хранятся в формате **RDF-подобных триплетов** `[Субъект] -> [Предикат] -> [Объект]`.

**Используемые файлы данных (CSV):**
* `safety_knowledge_triples_readable.csv` — База строительных норм, профессий и видов работ.
* `zhkh_safety_triples_readable.csv` — Специфика эксплуатации, аварий и ЖКХ.
* `construction_safety_ontology_extended.csv` — Макро-онтология жизненного цикла зданий, инженерных систем и законодательных актов (384-ФЗ, 116-ФЗ и др.).

## 🚀 Как запустить локально на MacOS / Linux / Windows

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python (версии 3.8 или выше). Откройте терминал и установите необходимые библиотеки:
```bash
pip install streamlit pandas
```

### 2. Запуск приложения
Перейдите в папку с загруженным проектом:
```bash
cd путь/к/вашей/папке
```
Запустите Streamlit:
```bash
streamlit run app.py
```
После ввода команды локальный сервер запустится, и приложение автоматически откроется в вашем браузере по адресу `http://localhost:8501`.

## 🌐 Как развернуть в облаке (Streamlit Community Cloud)
Если вы хотите опубликовать приложение для демонстрации коллегам:
1. Создайте публичный репозиторий на GitHub.
2. Загрузите туда 5 файлов: `app.py`, `requirements.txt` и три `.csv` файла с данными.
3. Зайдите на [share.streamlit.io](https://share.streamlit.io/) и авторизуйтесь через GitHub.
4. Нажмите **"New app"**, выберите свой репозиторий и укажите `app.py` как главный файл.
5. Нажмите **Deploy** — приложение будет доступно онлайн через пару минут!
